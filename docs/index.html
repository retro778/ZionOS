ZionOS

A Linux desktop based on Debian 13, in English and Hebrew.

מערכת הפעלה שולחנית מבוססת Debian 13, בעברית ובאנגלית.

Development preview (0.1.0 "Aleph"). ZionOS installs, runs and updates in our QEMU tests, but it is not a production release. It has not been tested on VirtualBox, VMware or physical hardware, and it has had no independent security review. Use it in a virtual machine. See the readiness report and known issues.

What it is

  • Debian 13 "trixie" underneath: the same kernel, packages, APT and security updates, unmodified.
  • KDE Plasma desktop, Firefox, LibreOffice, a graphical software centre and a graphical installer.
  • English by default; Hebrew selectable at boot, in the installer and afterwards. Right-to-left layout, Hebrew fonts, English and Hebrew keyboard layouts (Alt+Shift).
  • Three small ZionOS applications: Welcome, Settings and an optional AI assistant.
  • The assistant works only with your own OpenAI or Anthropic API key, kept in the desktop keyring. It suggests commands but never runs them. The system is fully usable without it.

Verify before use:

curl -O https://freedomnet.tech/zionos/zionos-archive-keyring.asc
gpg --import zionos-archive-keyring.asc
gpg --verify SHA256SUMS.asc SHA256SUMS      # must say "Good signature" with the fingerprint above
sha256sum -c --ignore-missing SHA256SUMS

Try it in a virtual machine (QEMU)

qemu-img create -f qcow2 zionos.qcow2 40G
qemu-system-x86_64 -enable-kvm -cpu host -m 4096 -smp 4 \
  -device virtio-vga -device qemu-xhci -device usb-tablet \
  -drive file=zionos.qcow2,if=virtio -cdrom zionos-0.1.0-amd64.iso

Choose "ZionOS Live", then press Install ZionOS in the Welcome window. The live session user is zion with password live; an installed system has no default password. Requirements: 64-bit PC, 4 GB RAM, 20 GB disk.

Updates

Almost everything updates straight from Debian. ZionOS's own packages come from a small signed repository, restricted so it can only ever provide zionos-* packages. Use the software centre, or sudo apt update && sudo apt full-upgrade.
